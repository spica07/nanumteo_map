# 공동육아나눔터 지도 (nanumteo_map) 설계

작성일: 2026-08-21

## 1. 무엇을 만드는가

전국 공동육아나눔터를 한 지도에서 찾아보는 PWA. 다있맵 계열 지도 프로젝트의 다음 번호이며, 빌드 도구 없이 정적 파일로 GitHub Pages에 올린다.

폴더는 `C:\blog_writing\nanumteo_map`.

공동육아나눔터는 여성가족부 산하 한국건강가정진흥원이 운영을 관리하는 돌봄 공간이다. 영유아·초등 저학년을 대상으로, 부모 그룹이 자율적으로 교대 돌봄(1회 2~4시간)을 하는 "품앗이 공동육아"를 센터가 매칭·모니터링하며, 발달단계별 놀이·체험 프로그램도 함께 제공한다. ('22) 376개소 → ('23) 395개소 → ('24) 435개소로 매년 늘고 있다.

## 2. 데이터

출처는 `한국건강가정진흥원_전국 공동육아나눔터 기관현황`(공공데이터포털, `data.go.kr/data/15055830/fileData.do`). CSV, 무키 다운로드, 430행(2025-12-08 최근 갱신 기준, 연 1회 갱신).

필드: 연번, 시도, 시군구, 주소(도로명), 운영기관, 연락처. **위경도는 없다.**

## 3. 좌표

원본에 좌표가 없으므로 `주소(도로명)`을 카카오 로컬 API로 지오코딩해 채운다. museum_map·library_map과 같은 패턴이다. 도로명주소가 비어 있거나 지오코딩이 실패하는 곳은 museum_map의 "수동 보강" 사례처럼 개별 확인이 필요할 수 있다 — 실제 다운로드 후 결측률을 확인한다.

## 4. 렌더링 방식

430곳은 규모가 작아 medicine_map·shelter_map류의 줌 단계별 집계(`render.js`)가 필요 없다. museum_map·library_map처럼 전체 마커를 한 번에 그리는 방식으로 충분하다.

## 5. 필터 · UI

- 지역(시도 → 시군구) 필터
- 이름 · 운영기관명 · 주소 검색
- 찜하기
- 유형 필터는 두지 않는다 — 원본에 시설 유형 분류가 없다.

## 6. 상세 화면

원본 필드 그대로: 시도, 시군구, 도로명주소, 운영기관명, 연락처. 여기에 **"운영시간과 이용 방법은 운영기관에 직접 문의하세요"** 안내 문구를 덧붙인다 — 원본에 장소별 운영시간·이용 방법이 없어서, 없는 정보를 지어내지 않고 문의를 안내하는 쪽을 선택했다(2026-08-21 사용자 결정).

별도로 **공통 안내 모달**을 하나 두어 제도 자체(대상 연령, 품앗이 공동육아 개념, 프로그램 유형)를 설명한다. 이 내용은 장소마다 다른 게 아니라 제도가 전국 공통이므로 medicine_map이 "13종 상비약" 안내를 앱에 고정해 둔 것과 같은 방식으로 처리한다.

## 7. 공통 규칙

- 국기 이모지를 포함해 이모지를 쓰지 않는다. 아이콘은 인라인 SVG(`class="ico"`, `viewBox="0 0 24 24"`).
- `report.html`은 수집·정제 리포트만 담고 메인 UI에서 버튼을 숨긴다.
- 독도를 항상 직접 표시한다(위도 37.2429 / 경도 131.8664, 경상북도 울릉군 울릉읍 독도리). `markDokdo()` + `.dokdo-label` 패턴을 그대로 쓴다.
- `assets/js/geo.js`("내 주변")는 워크스페이스 공통 원본(`shelter_map/assets/js/geo.js`)을 그대로 복사한다. `unitLabel`은 받침으로 끝나야 하므로 "나눔터" 그대로 쓸 수 있다("나눔터가 없어요").
- PWA(`sw.js`)로 오프라인 지원, 홈 화면 설치. 첫 배포 시 `CACHE` 버전은 v1부터 시작.
- 파이썬은 `python`이 아니라 `py`로 실행한다.

## 8. 파일 구조

```
index.html              지도 + 목록 + 제도 안내 모달
report.html             수집·정제 리포트 (UI에서 버튼 숨김)
assets/js/data.js       자동 생성. 직접 수정 금지
assets/js/geo.js        "내 주변" (워크스페이스 앱과 공용)
assets/js/app.js        필터·검색·목록·상세·안내 모달
tools/                  수집·지오코딩·아이콘 생성 스크립트
docs/superpowers/specs/ 설계 문서
sw.js                   서비스워커
```

## 9. 열어둔 것 (구현하며 확정)

- 실제 다운로드 후 CSV 인코딩(cp949 가능성), 주소 형식(도로명 누락 시 지번 병기 여부), 지오코딩 실패율을 확인한다.
- 연락처 형식(하이픈 유무 등) 정규화 방식은 원본을 보고 정한다.
- 저장소 GitHub 연결과 GitHub Pages 배포는 이번 스펙 범위 밖이다. 로컬 구현이 끝난 뒤 사용자 확인을 받아 진행한다.
- 이름은 `nanumteo_map`으로 잠정 확정(사용자 승인, 2026-08-21). 변경 요청 시 폴더명·저장소명을 함께 바꾼다.
